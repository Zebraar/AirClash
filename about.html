ЧАСТЫЕ ВОПРОСЫ

Игра бесплатная?

Да. Цель проекта — честный аэрохоккей без навязчивой рекламы и механик Pay-to-Win.

На каких платформах можно играть?

Сейчас доступен Android — APK можно скачать на GitHub или на itch.io (это просто страница для загрузки того же файла, не браузерная версия). А ещё прямо на этом сайте, на странице «Играть», есть отдельная браузерная мини-версия с реальной физикой и ботами. Клиент для Windows пока не выпущен.

Есть ли онлайн-игра с друзьями?

Да. Онлайн-мультиплеер с матчмейкингом уже полностью готов, а сыграть с другом можно прямо сейчас — через дружеский матч по коду комнаты. Отдельная система друзей (список и статус «в сети») пока в разработке.

Что с Эло и рейтингами?

Продвинутая Эло-система для онлайн-матчей уже работает и считает рейтинг по результатам игр. А вот таблицы глобального и регионального рейтинга ещё не готовы — их ждут в одном из следующих обновлений.

Как устроен ИИ бота?

Бот подстраивается под четыре уровня сложности — от «Лёгкого» до «Экстрима» — и ведёт себя не идеально, а «по-человечески»: с задержкой реакции и небольшими ошибками, которые уменьшаются на высоких уровнях.
